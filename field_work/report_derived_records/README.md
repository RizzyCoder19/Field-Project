# Report-derived fieldwork records

## Provenance and use

These files were compiled after the report was presented, using only the account in `report/finalized/0.pdf`. They are convenient summaries of what the report says. They are **not** original field notes, a verbatim interview transcript, a consent form, or an independent verification of the visit.

The report states that interview responses were paraphrased from notes and that no verbatim quotations are presented (printed pages 24 and 38–39). Accordingly, the interview summary below uses paraphrases only. No participant identity or new observation has been added.

The source records described in the report (original field notes, interview notes, consent documentation, and a completed evidence register) were not available in the repository during this compilation. The formal `field_work/07_FIELD_EVIDENCE_REGISTER.csv` remains unchanged and empty apart from its header. Do not cite these summaries as contemporaneous source evidence or use them to claim that missing source records have been recovered.

## Files

- `01_visit_record_report_derived.md` — visit metadata and reported study activities.
- `02_observation_summary_report_derived.md` — the three observations summarized in the report.
- `03_interview_summary_report_derived.md` — the five interview modules, paraphrased as presented in the report.
- `04_source_and_gap_register.csv` — report claims and the supporting repository artifact status.

## Unresolved consistency item

The report lists the visit as 10:30–11:45 a.m. (printed page 37). The website places an observation at 12:00 p.m. and its data comment describes observations through 12:00. The original notes were not available to resolve the difference, so these files retain the report's time and record the website discrepancy without deciding which is correct.
