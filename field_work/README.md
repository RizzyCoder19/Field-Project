# 🧪 Field Work Archive

This folder contains the project’s field-work archive, methodological framework, and supporting research materials.

## Purpose
The field archive is designed to document the research process around the disease analysis project, including:
- questionnaires
- interview guidance
- observation checklists
- ethics and privacy notes
- evidence register
- field-to-data linkage material

## Run locally
```bash
cd field_work
node server.mjs
```

Then open:
```text
http://127.0.0.1:8000
```
